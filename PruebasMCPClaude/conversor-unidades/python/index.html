📐 Conversor de unidades

Convierte entre unidades de longitud, peso y temperatura. El cálculo lo hace Python de verdad en tu navegador, gracias a Pyodide (WebAssembly) — sin servidor de por medio.

Esto es lo que corre en la demo de arriba — funciones puras que JavaScript llama a través de Pyodide en cada conversión:

LONGITUD_A_METROS = {
    "m": 1.0,
    "km": 1000.0,
    "cm": 0.01,
    "mm": 0.001,
    "milla": 1609.344,
    "pie": 0.3048,
    "pulgada": 0.0254,
}

PESO_A_KG = {
    "kg": 1.0,
    "g": 0.001,
    "mg": 0.000001,
    "libra": 0.45359237,
    "onza": 0.028349523125,
}

UNIDADES_TEMPERATURA = ["C", "F", "K"]


def convertir_longitud(valor, desde, hasta):
    metros = valor * LONGITUD_A_METROS[desde]
    return metros / LONGITUD_A_METROS[hasta]


def convertir_peso(valor, desde, hasta):
    kg = valor * PESO_A_KG[desde]
    return kg / PESO_A_KG[hasta]


def _a_celsius(valor, unidad):
    if unidad == "C":
        return valor
    if unidad == "F":
        return (valor - 32) * 5 / 9
    return valor - 273.15  # K


def _desde_celsius(valor_c, unidad):
    if unidad == "C":
        return valor_c
    if unidad == "F":
        return valor_c * 9 / 5 + 32
    return valor_c + 273.15  # K


def convertir_temperatura(valor, desde, hasta):
    return _desde_celsius(_a_celsius(valor, desde), hasta)


def unidades_disponibles(categoria):
    if categoria == "longitud":
        return list(LONGITUD_A_METROS.keys())
    if categoria == "peso":
        return list(PESO_A_KG.keys())
    if categoria == "temperatura":
        return UNIDADES_TEMPERATURA
    raise ValueError(f"Categoría desconocida: {categoria}")


def convertir(categoria, valor, desde, hasta):
    if categoria == "longitud":
        resultado = convertir_longitud(valor, desde, hasta)
    elif categoria == "peso":
        resultado = convertir_peso(valor, desde, hasta)
    elif categoria == "temperatura":
        resultado = convertir_temperatura(valor, desde, hasta)
    else:
        raise ValueError(f"Categoría desconocida: {categoria}")
    return round(resultado, 4)

Qué usa este ejemplo

  • Diccionarios de factores de conversión frente a una unidad base (metros para longitud, kilogramos para peso), para poder convertir entre cualquier par de unidades con una sola multiplicación y una división.
  • La temperatura se resuelve aparte porque no es una simple multiplicación: pasa siempre por Celsius como unidad intermedia.
  • Una función unidades_disponibles() que JavaScript llama para rellenar los desplegables dinámicamente según la categoría elegida, sin duplicar listas en HTML y en Python.
  • round() para presentar resultados legibles con 4 decimales.

Nada de bases de datos, credenciales ni conexiones externas: es un ejemplo autocontenido pensado solo para practicar.
