Cómo se juega

    
    
      
  1. Una ficha está libre cuando no tiene ninguna encima y, además, tiene despejado al menos uno de sus lados (izquierda o derecha). Las fichas libres se ven claras; las tapadas o encajonadas, rayadas y más apagadas, y los lectores de pantalla las anuncian como «tapada».
    2. 
      
  2. Elige dos fichas libres que hagan pareja y se retiran. Hacen pareja las que tienen el mismo dibujo (forma y color).
    3. 
      
  3. Las cuatro estaciones (primavera, verano, otoño e invierno) son una familia comodín: dos estaciones cualesquiera hacen pareja aunque sean distintas.
    4. 
      
  4. Ganas cuando no queda ninguna ficha.
    5. 
      
  5. Ojo: hay varias fichas iguales y no da igual con cuál haces la pareja. Si te quedas sin parejas libres, puedes deshacer la última o barajar: las fichas que quedan se recolocan y la nueva distribución siempre tiene salida. Las barajas son pocas (3 en fácil, 2 en normal y en difícil) y una baraja no se puede deshacer.
    6. 
      
  6. La pista (3 como máximo) te indica una pareja que sigue dejando una salida posible.
    7. 
      
  7. Estrellas: cada fallo (dos fichas libres que no son pareja) suma 1 punto de penalización, cada pista 2 y cada baraja 3. Con 2 o menos tienes tres estrellas; con 7 o menos, dos; si no, una. Elegir una ficha tapada no cuenta como fallo.
    8. 
      
  8. El reto diario es el mismo tablero para todo el mundo ese día (siempre difícil) y cuenta para la racha. En Práctica el tablero es aleatorio y no afecta a las estadísticas.
    9.

      Qué se busca con esta página
      
    
      Esta práctica quiere mostrar que un juego con una geometría un poco más seria (capas, solapes y una regla de «ficha libre») puede tener toda su lógica en Python, incluido un generador que garantiza solución y un solucionador, y publicarse como web estática sin servidor. El HTML, el CSS y un poco de JavaScript solo dibujan las fichas y avisan a Python de cada elección.
      
    
      Es también un ejercicio de diseño de sesiones cortas: se entiende en un minuto, cabe en un descanso y ofrece el mismo reto a todo el mundo cada día.
      
  
      

  
      
    
      Cómo está hecho
      
    
        
      
      • codigo.py contiene las reglas: los tres diseños de almacén, qué fichas están libres, la comprobación de parejas, las estaciones comodín, las pistas, las barajas, deshacer, las estrellas, el texto para compartir y la racha de días.
        • 
      
      • Fichas libres con máscaras de bits: para cada ficha se calculan una sola vez qué fichas la tapan y cuáles la tocan por la izquierda y por la derecha, y se guardan como números binarios. Saber si una ficha está libre es entonces un par de operaciones & sobre el número que representa las fichas vivas.
        • 
      
      • Siempre tiene solución: el tablero se construye al revés. Se parte de las posiciones llenas, se eligen dos fichas libres, se les da la misma pareja y se retiran; se repite hasta vaciarlo. Jugar es recorrer ese camino. La baraja usa el mismo método con las fichas que quedan, así que tampoco te deja atrapado.
        • 
      
      • Las pistas usan un solucionador de búsqueda en profundidad con memoria de estados ya vistos y un orden que prefiere las parejas que dejan más fichas libres. También descarta posiciones sin remedio, como un grupo de dos fichas en el que una tapa a la otra. Si no encuentra salida a tiempo, lo dice en lugar de inventar una.
        • 
      
      • El mismo tablero para todos: el reto diario convierte la fecha en una semilla (hash FNV-1a). Para que dé el mismo resultado en cualquier versión de Python, el generador de números aleatorios (mulberry32) está escrito dentro del propio archivo en lugar de usar el módulo random.
        • 
      
      • Python en el navegador: Pyodide ejecuta Python compilado a WebAssembly. script.js carga codigo.py, llama a sus funciones y recibe el estado como texto JSON.
        • 
      
      • Guardado: el reto del día guarda solo el historial de parejas y barajas, y se reconstruye repitiéndolo desde el tablero inicial, así que recargar la página no pierde el progreso.
        • 
      
      • Accesibilidad: cada dibujo se distingue por la forma y una letra, las fichas tapadas llevan rayas y la palabra «tapada» para lectores de pantalla, y se puede jugar solo con teclado.
