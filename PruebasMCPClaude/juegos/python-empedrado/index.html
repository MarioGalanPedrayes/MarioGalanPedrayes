Cómo se juega

    
    
      
  1. Cada casilla de la calle lleva una piedra o se queda vacía.
    2. 
      
  2. Las cifras a la izquierda de cada fila y encima de cada columna, en orden, dan la longitud de cada tramo de piedras seguidas. Por ejemplo, 3 1 es un tramo de tres piedras y, después, al menos un hueco y una piedra suelta. Un 0 es una línea sin ninguna piedra.
    3. 
      
  3. Pon piedras donde las cifras lo obliguen. Con la herramienta Hueco anotas «aquí seguro que no hay piedra»; es solo una nota para ti y no cuenta en la solución.
    4. 
      
  4. Cuando una fila o columna tiene sus tramos igual que las cifras, sus cifras se tachan y aparece una ✓.
    5. 
      
  5. Ganas cuando todas las filas y columnas están cumplidas.
    6. 
      
  6. Nunca hace falta adivinar: cada calle se puede resolver razonando línea a línea, y tiene una sola solución.
    7. 
      
  7. Pista coloca una casilla que se deduce con lógica. Revisar marca con una ! lo que tengas mal. Hay 3 de cada una, y las estrellas dependen de cuántas uses: 3 estrellas sin ayudas, 2 con una o dos, 1 con más. Deshacer es ilimitado.
    8. 
      
  8. El reto diario es la misma calle para todo el mundo ese día (la Plaza de 8×8) y cuenta para la racha. En Práctica la calle es aleatoria y no afecta a las estadísticas.
    9.

Qué se busca con esta página

    
Esta práctica quiere mostrar que un juego de lógica con solucionador incluido puede tener toda su lógica en Python y publicarse como web estática sin servidor. El HTML, el CSS y un poco de JavaScript solo dibujan la calle y avisan a Python de cada casilla que marcas.

    
También es un ejercicio de diseño sobre lo que funciona hoy en los juegos web: los puzles son lo que más se juega en el navegador, las sesiones duran pocos minutos, el reto diario es el mismo para todos y el resultado se puede compartir sin estropearle nada a nadie. Este es un puzle de deducción pura, sin azar ni prisa.

  


  

    
Cómo está hecho

    
    
      
  • codigo.py contiene las reglas: generar la calle, calcular las cifras, comprobar las líneas cumplidas, deshacer, las pistas, la revisión, las estrellas, el texto para compartir y la racha de días.
    • 
      
  • Sin adivinar y con solución única: cada calle se genera al azar y se pasa por un solucionador de lógica de líneas. Para cada fila o columna calcula todas las formas de colocar sus tramos que no contradicen lo ya sabido; si en todas ellas una casilla es piedra (o en todas es vacía), esa casilla queda decidida. Repite fila a fila y columna a columna hasta que no avanza. Solo se acepta la calle si el solucionador la completa entera; si no, se prueba otra parecida.
    • 
      
  • Las pistas usan el orden en que el solucionador fue decidiendo casillas: te da la primera que aún no tienes bien puesta, aunque tengas errores en otras partes.
    • 
      
  • La misma calle para todos: el reto diario convierte la fecha en una semilla (hash FNV-1a). Para que dé el mismo resultado en cualquier versión de Python, el generador de números aleatorios (mulberry32) está escrito dentro del propio archivo en lugar de usar el módulo random.
    • 
      
  • Python en el navegador: Pyodide ejecuta Python compilado a WebAssembly. script.js carga codigo.py, llama a sus funciones y recibe el estado como texto JSON.
    • 
      
  • Guardado: el reto del día guarda las casillas y las ayudas gastadas, así que recargar la página no pierde el progreso.
    • 
      
  • Accesibilidad: las marcas se distinguen por la forma y el texto (bloque, ×, !, ✓), no solo por el color; cada casilla tiene un nombre para lectores de pantalla, la primera de cada fila y columna lee también sus cifras, y se juega entero con teclado.
    • 
    

  


  

    
Originalidad

    
Deducir una cuadrícula a partir de las longitudes de los tramos de cada línea es una mecánica de lógica clásica y de uso libre. El nombre, el tema de la calle empedrada, las calles generadas al azar (no hay dibujos de terceros), la garantía de solución única sin adivinar, las pistas y la revisión limitadas, las estrellas, los textos y el diseño son propios; no se ha copiado ningún juego, personaje, imagen ni sonido. Todo se dibuja con CSS. Como motor de Python solo se usa Pyodide, cargado desde su CDN.
