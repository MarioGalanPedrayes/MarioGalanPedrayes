        Cómo se juega
        
    
          
      
        1. Estás en la palabra de salida. Escribe una palabra que se diferencie de la actual en una sola letra (cambiada de sitio no vale: la letra se sustituye en su misma posición). Por ejemplo, de casa a caso o a cosa.
          2. 
      
        2. Solo valen las palabras de la lista del juego (unas 500 de uso corriente). Si una palabra existe pero no sale, es que no está en la lista.
          3. 
      
        3. No se pisa dos veces la misma piedra ni las que están bajo el agua: son las que ha tapado la crecida y se ven arriba antes de empezar.
          4. 
      
        4. Ganas al pisar la palabra meta. El par es el menor número de pasos posible con la crecida ya contada, calculado de forma exacta.
          5. 
      
        5. Estrellas: 3 si llegas en el par o menos, 2 hasta dos pasos de más, 1 con más. Cada pista quita estrellas (una o dos pistas, una estrella; tres, dos), pero nunca bajas de una.
          6. 
      
        6. Pista (3 por partida) te dice la siguiente piedra de un camino mínimo desde donde estás. Deshacer es ilimitado. Si te quedas sin salida, el juego te avisa.
          7. 
      
        7. El reto diario es el mismo río para todo el mundo ese día (nivel Corriente) y cuenta para la racha. En Práctica eliges nivel y no afecta a las estadísticas.
          8. 
    
        
  
        

  
        
    
        Qué se busca con esta página
        
    
        Mostrar que un juego de palabras con solucionador exacto puede tener toda su lógica en Python y publicarse como web estática sin servidor. El HTML, el CSS y un poco de JavaScript solo dibujan el camino y avisan a Python de cada palabra que escribes.
        
    
        También es un ejercicio de diseño sobre lo que funciona hoy en el navegador: los puzles y los juegos de palabras dominan las sesiones cortas, el reto diario es igual para todos y el resultado se puede compartir sin desvelar nada. Aquí la tensión no viene de adivinar una palabra oculta, sino de planificar una ruta con un número de pasos como objetivo.
        
  
        

  
        
    
        Cómo está hecho
        
    
          
      
        • codigo.py contiene las reglas: la lista de palabras, el grafo de piedras, el generador de partidas, la validación de cada paso, las pistas, las estrellas, el texto para compartir y la racha.
          • 
      
        • El grafo: dos palabras son vecinas si se diferencian en una letra. Para construirlo sin comparar todas con todas, cada palabra se agrupa con las que comparten sus otras tres letras (c_sa reúne casa, cosa, cesa…).
          • 
      
        • El par exacto: una búsqueda en anchura desde la salida, sin pisar las piedras tapadas, da el menor número de pasos. La misma búsqueda sirve para las pistas (desde donde estás) y para avisar de que no hay salida.
          • 
      
        • La crecida: el generador elige salida y meta, y luego tapa palabras que estaban en algún camino mínimo, de modo que la ruta obvia deja de valer, pero comprueba siempre que sigue habiendo camino. El par que se enseña es el nuevo.
          • 
      
        • La misma partida para todos: el reto diario convierte la fecha en una semilla (hash FNV-1a) y el generador de números aleatorios (mulberry32) está escrito dentro del archivo, para que dé lo mismo en cualquier versión de Python.
          • 
      
        • Python en el navegador: Pyodide ejecuta Python compilado a WebAssembly. script.js carga codigo.py, llama a sus funciones y recibe el estado como texto JSON.
          • 
      
        • Guardado: el reto del día guarda el camino y las pistas gastadas; al recargar, Python vuelve a comprobar cada paso guardado.
          • 
      
        • Accesibilidad: el cambio de letra se marca con subrayado y negrita, no solo con color; hay avisos en texto para lectores de pantalla y se juega entero con teclado.
          • 
    
        
  
        

  
        
    
        Originalidad
        
    
        Pasar de una palabra a otra cambiando una letra por paso es un pasatiempo clásico de uso libre. El nombre, el tema del río, la lista de palabras (escrita para este juego, sin tomar ninguna lista de terceros), la crecida que tapa piedras, el par exacto, las pistas limitadas, las estrellas, los textos y el diseño son propios; no se ha copiado ningún juego, personaje, imagen ni sonido. Todo se dibuja con CSS. Como motor de Python solo se usa Pyodide, cargado desde su CDN.
