Cómo se juega

    
    
      
  1. El agua sale de la casilla con la fonte y avanza por los canales que se abren el uno hacia el otro.
    2. 
      
  2. Pulsa una casilla para girarla 90 grados. Hay finales, rectos, codos, T y cruces.
    3. 
      
  3. Ganas cuando las 36 casillas están regadas y no hay ninguna fuga: un brazo abierto que da al borde del prado o a una casilla que no se abre hacia él.
    4. 
      
  4. Las casillas fijas no giran y ya están bien colocadas: úsalas como punto de partida.
    5. 
      
  5. Cada giro cuenta. La referencia es el número mínimo de giros para reconstruir el trazado. Tres estrellas si no pasas de un 20 % por encima, dos estrellas hasta un 60 %, una si terminas. Deshacer no cuenta como giro; reiniciar empieza de cero.
    6. 
      
  6. El reto diario es el mismo prado para todo el mundo ese día y cuenta para la racha. En Práctica el prado es aleatorio y no afecta a las estadísticas.

    Qué se busca con esta página
    
    
    Esta práctica quiere mostrar que un juego completo puede tener toda su lógica en Python y publicarse como una web estática, sin servidor. El HTML, el CSS y un poco de JavaScript solo dibujan el prado y avisan a Python de cada giro.
    
    
    Es también un ejercicio de diseño: un rompecabezas de lógica espacial que se entiende en un minuto, que cabe en una sesión corta y que ofrece un mismo reto a todo el mundo cada día.
    
  
    

  
    
    
    Cómo está hecho
    
    
      
      
    • codigo.py contiene las reglas: generar el prado, girar casillas, calcular qué se riega y dónde hay fugas, deshacer, puntuar con estrellas, preparar el texto para compartir y llevar la racha de días.
      • 
      
    • Siempre tiene solución: el prado se genera dibujando primero un árbol aleatorio que une las 36 casillas (algoritmo de Kruskal con las aristas barajadas). De ese árbol salen las piezas; después se giran al azar, salvo las fijas. Las pruebas comprueban además con un solucionador independiente que cada prado se puede resolver, y que en casi todos la solución es única.
      • 
      
    • El mismo prado para todos: el reto diario convierte la fecha en una semilla (hash FNV-1a). Para que dé el mismo resultado en cualquier versión de Python, el generador de números aleatorios (mulberry32) está escrito dentro del propio archivo en lugar de usar el módulo random.
      • 
      
    • Python en el navegador: Pyodide ejecuta Python compilado a WebAssembly. script.js carga codigo.py, llama a sus funciones y recibe el estado como texto JSON.
      • 
      
    • Guardado: el reto del día guarda solo la lista de giros y se reconstruye repitiéndolos, así que recargar la página no pierde el progreso.
      • 
      
    • Accesibilidad: regada y seca se distinguen por el relleno (rayas o liso) y no solo por el color; las fugas, las fijas y la fonte tienen su propia marca; cada casilla tiene un nombre para lectores de pantalla y se puede jugar solo con teclado.
      • 
    
    
  
    

  
    
    
    Originalidad
    
    
    Girar piezas de canal para conectarlas es una mecánica de juego genérica y de uso libre. El nombre, el tema del prado y la fonte, la regla de las fugas, las casillas fijas, las estrellas, los textos y el diseño son propios; no se ha copiado ningún juego, personaje, imagen ni sonido de terceros. Todo se dibuja con CSS. Como motor de Python solo se usa Pyodide, cargado desde su CDN.
