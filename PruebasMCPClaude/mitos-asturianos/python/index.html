🐉 Quiz de mitos asturianos (Python)

La misma idea que la versión en Java, pero corriendo de verdad en tu navegador: 5 preguntas sobre Xanas, Cuélebres, el Trasgu, el Nuberu y el Busgosu. El cálculo lo hace Python de verdad gracias a Pyodide (WebAssembly), sin servidor de por medio.

Pruébalo

Pulsa el botón para barajar las preguntas y empezar la partida.

Código Python (versión navegador)

Esto es lo que corre en la demo de arriba — funciones puras que JavaScript llama a través de Pyodide para cada pregunta y cada respuesta:

import random

PREGUNTAS = [
    {
        "enunciado": "¿Cómo se llama el ser protector de los bosques y las minas en la mitología asturiana, descrito como un anciano pequeño y peludo?",
        "opciones": ["El Nuberu", "El Busgosu", "El Cuélebre", "El Trasgu"],
        "correcta": 1,
    },
    {
        "enunciado": "El Cuélebre es una gran serpiente alada que, según la leyenda, vigila un tesoro y vive muchos años. ¿Qué guardián suele acompañarlo o enfrentarse a él?",
        "opciones": ["La Xana", "El Sumiciu", "El Ñuberu", "El Diañu Burlón"],
        "correcta": 0,
    },
    {
        "enunciado": "¿Qué es una Xana en el folclore asturiano?",
        "opciones": ["Un gigante de piedra", "Un hada que habita en fuentes y ríos", "Un espíritu del fuego", "Un dragón marino"],
        "correcta": 1,
    },
    {
        "enunciado": "El Trasgu es un duende travieso muy conocido en Asturias. ¿Qué se dice que hay que hacer para librarse de sus travesuras en casa?",
        "opciones": ["Regalarle un gorro rojo", "Dejarle miel en la puerta", "Barrer al revés o esparcir semillas de mijo para que las cuente", "Cantarle una nana"],
        "correcta": 2,
    },
    {
        "enunciado": "¿A qué ser mitológico asturiano se le atribuye el control de las tormentas y el granizo?",
        "opciones": ["El Nuberu", "El Busgosu", "La Guaxa", "El Trasgu"],
        "correcta": 0,
    },
]

_barajadas = []


def iniciar_quiz():
    """Baraja las preguntas y las deja listas para la partida. Devuelve el total."""
    global _barajadas
    _barajadas = PREGUNTAS.copy()
    random.shuffle(_barajadas)
    return len(_barajadas)


def pregunta_actual(indice):
    """Devuelve el enunciado y las opciones de la pregunta en esa posición, sin desvelar la correcta."""
    p = _barajadas[indice]
    return {"enunciado": p["enunciado"], "opciones": p["opciones"]}


def comprobar_respuesta(indice_pregunta, indice_opcion):
    """Comprueba si la opción elegida es la correcta y devuelve el texto de la respuesta correcta."""
    p = _barajadas[indice_pregunta]
    return {
        "correcta": indice_opcion == p["correcta"],
        "respuesta_correcta": p["opciones"][p["correcta"]],
    }


def mensaje_final(aciertos, total):
    ratio = aciertos / total
    if ratio == 1:
        return "¡Excelente! Conoces bien la mitología asturiana."
    if ratio >= 0.6:
        return "Buen resultado, pero aún hay mitos por descubrir."
    return "Te vendría bien repasar las leyendas asturianas."

⬇ Descargar codigo.py (versión de consola con input(), para ejecutar con python codigo.py en tu ordenador).

Qué usa este ejemplo

  • random.shuffle() para variar el orden de las preguntas en cada partida.
  • Funciones puras en Python (sin input()/print()) que JavaScript invoca directamente con pyodide.runPythonAsync(), pasando el estado del quiz por parámetros en vez de por consola.
  • Conversión de diccionarios Python a objetos JavaScript con toJs({ dict_converter: Object.fromEntries }).
  • Comparación con la versión en Java de la misma carpeta padre: mismo contenido, dos formas distintas de ejecutarlo (en el navegador vs. en tu ordenador).

Nada de bases de datos, credenciales ni conexiones externas: es un ejemplo autocontenido pensado solo para practicar.
