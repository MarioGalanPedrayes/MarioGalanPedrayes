📊 Encuesta con resultados en vivo (PHP)

Una encuesta de consola sobre lenguajes de programación favoritos: cada voto redibuja al instante las barras de porcentaje de todas las opciones, para ver los resultados actualizarse "en vivo" según se vota.

⚠️ Este código no se ejecuta en esta página

GitHub Pages solo puede ejecutar HTML, CSS y JavaScript en el navegador — no tiene servidor, así que no puede correr PHP ni guardar votos de verdad entre distintas personas. El código de abajo es real y funcional, pero para probarlo tienes que ejecutarlo en tu ordenador:

  1. Instala PHP si no lo tienes (php.net, o simplemente sudo apt install php-cli en Linux).
  2. Descarga codigo.php (link abajo).
  3. Abre una terminal en esa carpeta y ejecuta:
php codigo.php

⬇ Descargar codigo.php

"En vivo" aquí significa que los resultados se recalculan al instante en tu propia terminal tras cada voto que tú mismo metas, no que varias personas voten a la vez desde sitios distintos — eso ya requeriría un servidor con base de datos.

Código completo

<?php
/**
 * Encuesta con resultados en vivo (consola).
 * Autocontenida: sin dependencias externas, sin acceso a red ni a
 * ficheros del sistema. Los votos solo existen durante la ejecución.
 */

function pedirNumero(string $mensaje): int
{
    echo $mensaje;
    $linea = trim(fgets(STDIN));
    return (int) $linea;
}

function dibujarBarra(int $valor, int $total, int $ancho = 30): string
{
    if ($total === 0) {
        return str_repeat('░', $ancho) . '   0.0%';
    }

    $porcentaje = $valor / $total;
    $llenas = (int) round($porcentaje * $ancho);
    $barra = str_repeat('█', $llenas) . str_repeat('░', $ancho - $llenas);

    return sprintf('%s  %5.1f%%', $barra, $porcentaje * 100);
}

function mostrarResultados(array $opciones, array $votos): void
{
    $total = array_sum($votos);
    echo "\n--- Resultados en vivo ({$total} votos) ---\n";

    foreach ($opciones as $i => $opcion) {
        $etiqueta = str_pad($opcion, 12);
        echo "{$etiqueta} " . dibujarBarra($votos[$i], $total) . " ({$votos[$i]})\n";
    }

    echo "\n";
}

function main(): void
{
    $opciones = ['Python', 'JavaScript', 'PHP', 'Java', 'Otro'];
    $votos = array_fill(0, count($opciones), 0);
    $salir = count($opciones) + 1;

    echo "=== Encuesta en vivo: tu lenguaje favorito ===\n\n";

    while (true) {
        foreach ($opciones as $i => $opcion) {
            echo ($i + 1) . ") {$opcion}\n";
        }
        echo "{$salir}) Terminar encuesta\n";

        $eleccion = pedirNumero("Vota (numero): ");

        if ($eleccion === $salir) {
            break;
        }

        $indice = $eleccion - 1;
        if ($indice < 0 || $indice >= count($opciones)) {
            echo "Opcion no valida, intentalo de nuevo.\n\n";
            continue;
        }

        $votos[$indice]++;
        mostrarResultados($opciones, $votos);
    }

    echo "=== Resultado final ===\n";
    mostrarResultados($opciones, $votos);
}

main();

Qué usa este ejemplo

  • Un array asociativo simple ($votos) indexado por posición, que hace de "base de datos" en memoria mientras el programa está en ejecución.
  • Una función dibujarBarra() que genera una barra de progreso ASCII a partir de un porcentaje, usando str_repeat() y sprintf() para el formato con decimales.
  • array_sum() para calcular el total de votos y recalcular los porcentajes de todas las opciones en cada vuelta del bucle.
  • Bucle principal con menú que se repite hasta que el usuario decide terminar la encuesta, mostrando el resumen final al salir.

Nada de bases de datos reales, credenciales ni conexiones externas: es un script autocontenido pensado solo para practicar.
