⏱️ Sumatorio de horas, minutos, segundos y milisegundos

Añade varias duraciones y súmalas todas de golpe: el resultado se normaliza automáticamente (por ejemplo, 70 segundos se convierten en 1 minuto y 10 segundos). El cálculo lo hace Python de verdad en tu navegador, gracias a Pyodide (WebAssembly).

Pruébalo

Código Python (versión navegador)

Esto es lo que corre en la demo de arriba — funciones puras que JavaScript llama a través de Pyodide con la lista de duraciones que hayas introducido:

def duracion_a_ms(horas, minutos, segundos, milisegundos):
    return ((horas * 3600 + minutos * 60 + segundos) * 1000) + milisegundos


def normalizar(total_ms):
    total_ms = int(total_ms)
    milisegundos = total_ms % 1000
    total_s = total_ms // 1000
    segundos = total_s % 60
    total_m = total_s // 60
    minutos = total_m % 60
    horas = total_m // 60
    return {"horas": horas, "minutos": minutos, "segundos": segundos, "milisegundos": milisegundos}


def sumar_duraciones(duraciones):
    """duraciones: lista de listas [horas, minutos, segundos, milisegundos]."""
    total_ms = 0
    for h, m, s, ms in duraciones:
        total_ms += duracion_a_ms(h, m, s, ms)

    resultado = normalizar(total_ms)
    resultado["total_ms"] = total_ms
    resultado["total_segundos"] = round(total_ms / 1000, 3)
    return resultado


def formatear(horas, minutos, segundos, milisegundos):
    return "{:02d}:{:02d}:{:02d}.{:03d}".format(horas, minutos, segundos, milisegundos)

Qué usa este ejemplo

  • Conversión de cada duración a un único número de milisegundos, para poder sumarlas todas sin manejar el acarreo (horas, minutos, segundos) manualmente durante la suma.
  • Una función normalizar() que, al final, deshace esa conversión repartiendo el total entre horas, minutos, segundos y milisegundos con divisiones y módulos (// y %).
  • Formato con ceros a la izquierda ({:02d}, {:03d}) para mostrar siempre "01:05:03.007" en vez de "1:5:3.7".
  • En el navegador, filas de inputs añadidas y eliminadas dinámicamente con JavaScript, convertidas a una lista de Python con pyodide.toPy() antes de pasarlas a sumar_duraciones().

Nada de bases de datos, credenciales ni conexiones externas: es un ejemplo autocontenido pensado solo para practicar.
