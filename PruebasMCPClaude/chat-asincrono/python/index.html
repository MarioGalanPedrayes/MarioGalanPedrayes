💬 Chat asíncrono (simulación con asyncio)

Tres usuarios "escriben a la vez": cada uno manda varios mensajes con un pequeño retraso aleatorio, y se ven llegar intercalados en tiempo real. No hay servidor ni red de por medio — es asyncio corriendo de verdad en tu navegador gracias a Pyodide (WebAssembly), usando el propio bucle de eventos del navegador para las esperas.

⚠️ No es un chat real entre distintas personas ni distintas pestañas: es una demo pensada para ver cómo async/await permite que varias tareas avancen "a la vez" sin bloquearse entre sí.

Código Python (versión navegador)

Esto es lo que corre en la demo de arriba: tres corrutinas ejecutándose a la vez con asyncio.gather(), cada una avisando a JavaScript en cuanto "llega" uno de sus mensajes:

import asyncio
import random
from datetime import datetime
from js import agregarMensajeJS

MENSAJES = {
    "Ana": [
        "¿Alguien ha visto el correo del cliente?",
        "Lo reviso ahora mismo",
        "Perfecto, gracias",
    ],
    "Bruno": [
        "Estoy terminando el despliegue",
        "Ya está en producción",
        "Todo verde en el pipeline",
    ],
    "Clara": [
        "¿Quedamos a las 17:00 para la reunión?",
        "Por mí vale",
        "Nos vemos entonces",
    ],
}


async def enviar_mensajes(usuario, mensajes):
    """Cada mensaje espera su propio retraso aleatorio y, en cuanto
    'llega', avisa a JavaScript para pintarlo en el chat al instante."""
    for texto in mensajes:
        retraso = random.uniform(0.3, 1.5)
        await asyncio.sleep(retraso)
        hora = datetime.now().strftime("%H:%M:%S")
        agregarMensajeJS(usuario, texto, hora)


async def iniciar_chat():
    tareas = [
        enviar_mensajes(usuario, mensajes)
        for usuario, mensajes in MENSAJES.items()
    ]
    # Las tres conversaciones corren a la vez: el navegador sigue
    # respondiendo mientras cada mensaje espera su turno.
    await asyncio.gather(*tareas)

⬇ Descargar codigo.py (versión de consola, para ejecutar con python codigo.py en tu ordenador).

Qué usa este ejemplo

  • async def / await para definir corrutinas: funciones que pueden "pausarse" en un await sin bloquear el resto del programa.
  • asyncio.sleep() para simular la espera antes de cada mensaje, sin congelar la página — otras corrutinas siguen avanzando mientras una espera.
  • asyncio.gather() para lanzar las tres conversaciones a la vez y esperar a que todas terminen.
  • En la versión de navegador, from js import agregarMensajeJS permite que Python llame directamente a una función JavaScript cada vez que un mensaje está listo, así que el chat se pinta en vivo según van llegando los mensajes, no todo de golpe al final.

Nada de bases de datos, credenciales ni conexiones externas: es un ejemplo autocontenido pensado solo para practicar concurrencia con asyncio.
