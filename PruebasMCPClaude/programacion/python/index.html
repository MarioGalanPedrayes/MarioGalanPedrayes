Objetivo de la práctica

Practicar lo básico de Python con un caso pequeño y completo: listas, diccionarios, funciones, condicionales y números aleatorios. Además, ver cómo Python se puede conectar con una página web usando Pyodide.

Cómo está hecho

  • codigo.py guarda las reglas en un diccionario (VENCE_A): cada jugada vence a una sola. Así no hace falta escribir nueve comparaciones.
  • La función resolver() compara las dos jugadas y devuelve quién gana.
  • La función jugar() elige la jugada del ordenador con random.choice(), actualiza el marcador y devuelve el resultado en JSON.
  • script.js carga Pyodide, ejecuta codigo.py y llama a sus funciones cuando pulsas un botón. No hay servidor: todo ocurre en tu navegador.

Qué se busca con ella

Que se entienda que la lógica del juego (Python) está separada de la presentación (HTML, CSS y JavaScript). Con ese patrón se puede cambiar el aspecto sin tocar las reglas, y viceversa.
