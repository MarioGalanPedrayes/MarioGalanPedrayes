🎬 Animación de bolas rebotando

Varias bolas caen por gravedad y rebotan en los bordes del lienzo, perdiendo energía en cada rebote hasta asentarse. Toda la física (gravedad, movimiento, rebote) la calcula Python de verdad en cada fotograma, gracias a Pyodide (WebAssembly); JavaScript solo se encarga de dibujar el resultado en el <canvas>.

Pruébalo

Código Python (versión navegador)

Esto es lo que corre en la demo de arriba — avanzar() se llama una vez por fotograma (hasta 60 veces por segundo) y devuelve la nueva posición de cada bola:

import random

GRAVEDAD = 0.5
REBOTE = 0.82

_bolas = []


def iniciar(cantidad, ancho, alto):
    """Crea 'cantidad' bolas con posición, velocidad, radio y color al azar."""
    global _bolas
    colores = ["#6ee7b7", "#60a5fa", "#f0abfc", "#fbbf24", "#f87171", "#a78bfa"]
    _bolas = []

    for i in range(cantidad):
        radio = random.uniform(12, 26)
        bola = {
            "x": random.uniform(radio, ancho - radio),
            "y": random.uniform(radio, alto / 2),
            "vx": random.uniform(-5, 5),
            "vy": random.uniform(-2, 2),
            "radio": radio,
            "color": colores[i % len(colores)],
        }
        _bolas.append(bola)

    return len(_bolas)


def avanzar(ancho, alto):
    """Calcula el siguiente frame: aplica gravedad, mueve cada bola y
    la hace rebotar en los bordes del lienzo. Devuelve el nuevo estado."""
    for bola in _bolas:
        bola["vy"] += GRAVEDAD
        bola["x"] += bola["vx"]
        bola["y"] += bola["vy"]

        if bola["x"] - bola["radio"] < 0:
            bola["x"] = bola["radio"]
            bola["vx"] = -bola["vx"] * REBOTE
        elif bola["x"] + bola["radio"] > ancho:
            bola["x"] = ancho - bola["radio"]
            bola["vx"] = -bola["vx"] * REBOTE

        if bola["y"] - bola["radio"] < 0:
            bola["y"] = bola["radio"]
            bola["vy"] = -bola["vy"] * REBOTE
        elif bola["y"] + bola["radio"] > alto:
            bola["y"] = alto - bola["radio"]
            bola["vy"] = -bola["vy"] * REBOTE

    return _bolas

Qué usa este ejemplo

  • Un bucle de animación con requestAnimationFrame en JavaScript, que en cada fotograma llama directamente a la función Python avanzar() (sin pasar por runPythonAsync, para que sea lo bastante rápido para 60 fotogramas por segundo).
  • El estado de las bolas (posición, velocidad, radio, color) vive por completo en Python, como una variable global que se actualiza en cada llamada — JavaScript solo la lee para dibujar, nunca la modifica.
  • Física simple: se suma la gravedad a la velocidad vertical en cada paso, se actualiza la posición, y al chocar con un borde se invierte la velocidad multiplicándola por un factor de rebote menor que 1 (para que pierda energía y acabe asentándose).
  • Conversión de la lista de diccionarios de Python a objetos JavaScript con toJs({ dict_converter: Object.fromEntries }) para poder dibujarlos con la API de canvas.

Nada de bases de datos, credenciales ni conexiones externas: es un ejemplo autocontenido pensado solo para practicar.
