# Juegos

## SEMILLA CERO — Jardín gravitatorio

Puzle por turnos desarrollado con Python y Pyodide. Recoge las gotas de agua y guía una semilla hasta la tierra fértil mientras la gravedad cambia de dirección en cinco jardines.

[Jugar a SEMILLA CERO](https://MarioGalanPedrayes.github.io/MarioGalanPedrayes/PruebasMCPCHATGPT/juegos/semilla-cero/).


## FRECUENCIA — Código fantasma

Juego de deducción por turnos desarrollado con Python y Pyodide. Descifra cinco transmisiones con secuencias de símbolos sin repetir, interpreta las coincidencias y administra los intentos disponibles.

[Jugar a FRECUENCIA](https://MarioGalanPedrayes.github.io/MarioGalanPedrayes/PruebasMCPCHATGPT/juegos/frecuencia/).


## TRAZA: Rescate orbital

Aventura de lógica por turnos desarrollada con Python y Pyodide. Guía un robot por cinco sectores, recupera núcleos de energía y alcanza cada compuerta antes de agotar la batería.

[Jugar a TRAZA](https://MarioGalanPedrayes.github.io/MarioGalanPedrayes/PruebasMCPCHATGPT/juegos/traza/).

Proyectos de juegos ejecutables desde navegador.

## DERIVA — Cartógrafo de Mareas

Puzle táctico de navegación por turnos desarrollado con Python y Pyodide. Recupera boyas científicas, aprovecha corrientes cambiantes y alcanza el faro en cinco mapas.

[Jugar a DERIVA](https://MarioGalanPedrayes.github.io/MarioGalanPedrayes/PruebasMCPCHATGPT/juegos/deriva/).

## NODO 7 — Clasificador de señales

Juego de lógica logística desarrollado con Python y Pyodide. Clasifica paquetes por color, forma y ritmo en seis expedientes, con filtros simples y compuestos, rachas, pistas y límite de errores.

[Jugar a NODO 7](https://MarioGalanPedrayes.github.io/MarioGalanPedrayes/PruebasMCPCHATGPT/juegos/nodo-7/).

## BROTE: Ecosistema Perdido

Juego web cozy de exploración, cultivo y restauración de un pequeño ecosistema. Cliente HTML, CSS y JavaScript, con guardado local de la partida.

Consulta `brote/README.md` para jugar y conocer sus mecánicas.

## PRISMA: Archivo de Luz

Puzle de lógica óptica en cinco expedientes. Gira espejos para conducir un haz de luz hasta el receptor. Aplicación web estática con HTML, CSS, JavaScript y SVG originales.

Consulta `prisma/README.md` para las reglas y el acceso al juego.
