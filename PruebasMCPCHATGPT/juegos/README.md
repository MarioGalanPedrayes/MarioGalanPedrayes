# Juegos

Proyectos de juegos ejecutables desde navegador.

## BROTE: Ecosistema Perdido

Juego web cozy de exploración, cultivo y restauración de un pequeño ecosistema. Cliente HTML, CSS y JavaScript, con guardado local de la partida.

Consulta `brote/README.md` para jugar y conocer sus mecánicas.

## VOIDRUN: SECTOR 9

Roguelite arcade de ciencia ficción, desarrollado en Python con Pygame-CE y preparado para compilarse a WebAssembly mediante Pygbag. Sobrevive a oleadas, derrota jefes y elige mejoras.

Consulta `voidrun/README.md` para controles, instalación y compilación para GitHub Pages.

## PRISMA: Archivo de Luz

Puzle de lógica óptica en cinco expedientes. Gira espejos para conducir un haz de luz hasta el receptor. Aplicación web estática con HTML, CSS, JavaScript y SVG originales.

Consulta `prisma/README.md` para las reglas y el acceso al juego.
