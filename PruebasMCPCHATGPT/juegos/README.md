# Juegos

Proyectos de juegos ejecutables desde navegador.

## NODO 7 — Clasificador de señales

Juego de lógica logística desarrollado con Python y Pyodide. Clasifica paquetes por color, forma y ritmo en seis expedientes, con filtros simples y compuestos, rachas, pistas y límite de errores.

[Jugar a NODO 7](https://MarioGalanPedrayes.github.io/MarioGalanPedrayes/PruebasMCPCHATGPT/juegos/nodo-7/).

## BROTE: Ecosistema Perdido

Juego web cozy de exploración, cultivo y restauración de un pequeño ecosistema. Cliente HTML, CSS y JavaScript, con guardado local de la partida.

Consulta `brote/README.md` para jugar y conocer sus mecánicas.

## VOIDRUN: SECTOR 9

Roguelite arcade de ciencia ficción, documentado como juego Python/Pygame-CE y Pygbag. La compilación y los archivos de juego quedan pendientes de verificación en la ruta de ChatGPT.

Consulta `voidrun/README.md` cuando esté disponible.

## PRISMA: Archivo de Luz

Puzle de lógica óptica en cinco expedientes. Gira espejos para conducir un haz de luz hasta el receptor. Aplicación web estática con HTML, CSS, JavaScript y SVG originales.

Consulta `prisma/README.md` para las reglas y el acceso al juego.
