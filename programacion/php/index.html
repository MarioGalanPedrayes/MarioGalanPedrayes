🎯 Adivina el número (PHP)

Juego de consola clásico: el programa piensa un número del 1 al 100 y te da pistas de "más alto" / "más bajo" hasta que aciertes o se acaben los intentos.

⚠️ Este código no se ejecuta en esta página

GitHub Pages solo puede ejecutar HTML, CSS y JavaScript en el navegador — no tiene servidor, así que no puede correr PHP. El código de abajo es real y funcional, pero para jugar tienes que ejecutarlo en tu ordenador:

  1. Instala PHP si no lo tienes (php.net, o simplemente sudo apt install php-cli en Linux).
  2. Descarga codigo.php (link abajo).
  3. Abre una terminal en esa carpeta y ejecuta:
php codigo.php

⬇ Descargar codigo.php

Código completo

<?php
function pedirNumero(string $mensaje): int
{
    echo $mensaje;
    $linea = trim(fgets(STDIN));
    return (int) $linea;
}

function main(): void
{
    $secreto = random_int(1, 100);
    $intentosMaximos = 7;
    $intento = 0;

    echo "=== Adivina el numero (1-100) ===\n";
    echo "Tienes {$intentosMaximos} intentos.\n\n";

    while ($intento < $intentosMaximos) {
        $intento++;
        $restantes = $intentosMaximos - $intento;
        $numero = pedirNumero("Intento {$intento}/{$intentosMaximos} - Escribe un numero: ");

        if ($numero === $secreto) {
            echo "Correcto! El numero era {$secreto}. Lo lograste en {$intento} intentos.\n";
            return;
        }

        echo $numero < $secreto ? "Mas alto. " : "Mas bajo. ";
        if ($restantes > 0) {
            echo "Te quedan {$restantes} intentos.\n";
        }
    }

    echo "Se acabaron los intentos. El numero era {$secreto}.\n";
}

main();

Qué usa este ejemplo

  • random_int() — generación de números aleatorios criptográficamente segura (mejor práctica que rand()).
  • Entrada por consola con fgets(STDIN).
  • Tipado de parámetros y retorno (string, int, void), disponible desde PHP 7+.

Nada de bases de datos, credenciales ni conexiones externas: es un script autocontenido pensado solo para practicar.
